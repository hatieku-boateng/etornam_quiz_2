# Simple and Multiple Linear Regression

This project is a beginner-friendly Jupyter Notebook that demonstrates and compares Simple Linear Regression (SLR) and Multiple Linear Regression (MLR) with Python and scikit-learn.

## What the notebook does

The notebook runs from top to bottom and:

1. Creates a reproducible synthetic dataset of 5,000 observations using a fixed random seed.
2. Saves the dataset to `regression_data.csv`, then loads it into a pandas DataFrame and previews its shape and first rows.
3. Splits the data into training and test sets, trains an SLR model using `hours_studied`, and trains an MLR model using `hours_studied`, `practice_tests`, `attendance_rate`, and `sleep_hours`.
4. Evaluates both models on the held-out test set with Mean Squared Error (MSE), Mean Absolute Error (MAE), and R².
5. Explores feature distributions, exam-score distributions, the relationship between study hours and exam score, and correlations.
6. Visualizes MLR coefficients, actual versus predicted test scores, residual patterns and distributions, and additional error comparisons.
7. Shows actual and predicted scores with residual annotations for 10 test observations for each model.

The notebook explains the metrics, model coefficients, plots, and residuals, including how to interpret positive and negative residuals.

## Project files

- `linear_regression_comparison.ipynb` - the notebook containing the data generation, analysis, models, and visualizations.
- `requirements.txt` - Python packages required to run the notebook.
- `.gitignore` - excludes the virtual environment, Python caches, Jupyter checkpoints, and generated dataset from Git.
- `regression_data.csv` - generated by the notebook when it runs; it does not need to exist beforehand.

## Set up

From the project folder, create and activate a virtual environment in PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, run the environment's Python executable directly instead:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m jupyter lab
```

## Run the notebook

Start Jupyter Lab from the activated environment:

```powershell
python -m jupyter lab
```

Open `linear_regression_comparison.ipynb` in the browser, select the `.venv` Python kernel if prompted, and run all cells from top to bottom. The notebook creates or overwrites `regression_data.csv` in the current project folder.
